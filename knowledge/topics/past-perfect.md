# Topic: Past Perfect

## Objective
Teach the past perfect as the tense for showing that one past action happened before another past point.

## Teaching Strategy

### 1. The "Past Before the Past"
- Build it with "had" + past participle.
- "I had finished." "She had left."
- Use it when the student needs to make the order of past events very clear.
- Ask: "Which action happened first, before the other past moment?"

### 2. Sequence and Context
- "When I arrived, they had already eaten."
- "By the time we got there, the movie had started."
- The past perfect gives background time that sits further back than the main past event.
- Ask: "What had already happened before the arrival?"

### 3. Not Every Story Needs It
- If the order is already obvious, English often stays simple.
- Use the past perfect when clarity matters, not in every sentence.
- This helps the student avoid overusing it.

## Block-Building Example
- "They" + "had already left"
- "when" + "I arrived"
- Combine: "They had already left when I arrived."

## Common Pitfalls
- Using the past perfect for a single finished past action with no earlier past reference.
- Confusing "had" as possession instead of the helper verb.
- Using the wrong participle after "had."
- Guide the student to discover the timeline: "Which past action is older?"

## Connection to Other Concepts
- Supports third-conditional-regret because the "if" clause uses the same form.
- Connects naturally to past-continuous-narrative when telling more detailed stories.
